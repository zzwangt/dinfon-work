# 鼎峰 · 项目管理平台

这是一个可操作的管理平台框架，适合先用示例项目验证流程与界面。所有项目、人员和审批记录均为演示数据。原生 HTML/CSS/JavaScript，无需安装依赖。

## 启动

在本目录打开终端，执行：

```sh
npm start
```

打开 http://127.0.0.1:4173 。也可以双击 `启动平台.command`。需要本机 Python 3；测试另需 Node.js 20 或更高版本。

不要直接双击 `dist/index.html`：ES modules 需要通过 HTTP 打开。

## 已实现的范围

- 流程画布：大节点显示阶段/周目标，小节点显示任务，支持缩放、适应画布、横向浏览、节点点击及视图切换。
- 项目与成员：创建项目、指定负责人及参与人，查看项目详情。
- 流程计划：创建有权重的周节点，分配任务、责任人、验收人和截止日期。
- 日常工作：开始任务、反馈阻塞、提交成果、验收通过或退回修改。
- 周汇总：按周查看到期节点与任务，生成报告并导出。
- 管理后台：全部项目进度、大小节点状态、待验收、逾期、人员统计、延期与审批记录。
- 周必达标记：本周及以前未完成的大节点突出标记；已逾期为红色，未来周节点不误标。只有明确获批调整的节点日期才会变化。
- 团队统计：完成率、按时提交率、一次验收通过率及其分子/分母。
- 延期申请：填写原因、申请日期、影响和调整计划；可以指定受影响的任务/节点日期。
- 后台审批：审批通过后统一变更日期，驳回或待审批状态保留原计划，留下审批记录。
- 数据：浏览器本地保存、JSON 导出、演示数据重置。

## 推荐体验顺序

1. 以默认管理人员进入项目流程，查看大节点、小任务与本周必达标记；在管理后台查看全部项目数据。
2. 进入一个项目，查看任务计划和周节点。
3. 用顶部“演示身份”切换到任务负责人，提交成果。
4. 切换到该任务验收人或非执行人的管理人员，进行验收。
5. 用项目负责人身份申请延期，填写原因及新截止日期。
6. 切换到另一位有审批权限的管理人员，批准或驳回。
7. 回到项目详情，核对原计划、当前计划、关联任务和审批记录。
8. 刷新页面确认数据仍在，进入设置导出数据备份。

## 统计口径

- 项目进度 = 已验收节点权重 / 全部节点权重。没有节点时显示 0%。节点只有在至少存在一条关联任务且全部验收通过后才可完成。
- 计划完成率 = 所选周期内到期且已验收完成的任务 / 所选周期内全部计划到期任务。当前周包含尚未到期任务，用于观察计划执行，不直接作为员工绩效排名。
- 按时提交率：以提交成果版本的时间与任务当前批准截止日期比较，独立于验收人的处理速度。
- 一次验收通过率 = 首次验收通过任务 / 已完成首次验收任务。
- 分母为 0 时显示“—”，同时保留实际数量。
- 原始截止日期不会被延期审批覆盖。当前统计按批准后的截止日期组织，原计划在详情和审批历史中可查。

## 边界

本框架不是已配置完成的企业生产系统：

- 数据仅保存在当前浏览器、当前网址的 localStorage；不同设备、浏览器或预览/发布网址之间不共享。
- “演示身份”用于验证角色操作，不是真实登录或安全隔离。浏览器端权限校验可被修改，不能保护真实公司资料。
- 尚无服务器数据库、企业账号、多人同步、实际消息推送、定时任务、二进制附件上传或自动备份。
- 成果目前使用文字说明或链接；导出的 JSON 可用于保留和后续迁移数据，本版尚无备份导入。
- 发布为个人私有访问时，站点的访问门槛与应用中的企业角色权限是两回事。

正式上线前应将业务规则迁至服务端、接入账号与数据库、添加文件存储与通知，并验证多用户并发、授权、审计和备份恢复。建议先用一个真实但不敏感的项目跑一周，确定管理口径后继续开发。

## 源码结构

```text
dist/index.html      页面入口
dist/app.js          视图、表单、导航与浏览器存储
dist/styles.css      界面设计与响应式样式
dist/app.css         特定页面补充样式
dist/flow.js         大小节点流程画布与缩放平移
dist/flow.css        流程节点与连线样式
dist/domain.js       项目、任务、审批和统计规则
tests/              业务规则测试
.openai/hosting.json 私有站点部署声明
PRODUCT.md           需求与本轮边界
DESIGN.md            界面约定
```

## 检查

```sh
npm test
npm run check
```

数据变更通过 `transact` 统一处理，UI 不直接修改任务和审批状态。后续接入服务器时可复用数据模型与测试，存储和权限必须迁移到受信任的服务端。
