# 鼎峰协同 · 独立账号版

公司项目管理平台，支持电脑网页与可添加到手机桌面的 PWA。员工使用公司分配的账号和密码登录，不需要 ChatGPT 账号。此版本为可部署源码，尚未部署到国内正式服务器；原 chatgpt.site 站点不会因本地改动自动更新。

## 本机启动

需要 Node.js 24 或更高版本。独立服务不需要安装 npm 依赖，前端资源全部随包提供，没有第三方登录或远程字体依赖。

```sh
npm run setup
npm start
```

初始化在终端中设置访问网址、管理员账号和密码；密码不回显、不保存明文。默认网址为 http://127.0.0.1:3000。Mac 也可双击 `启动平台.command`。正式部署、HTTPS、备份与管理员恢复见 [DEPLOYMENT.md](DEPLOYMENT.md)。

全新部署只创建一名管理员和空工作空间。已有独立账号数据库升级时，保留原有账号、项目与任务归属。旧浏览器、旧服务器的数据不会自动导入。演示项目仅在明确设置 `SEED_DEMO_DATA=true` 时生成，不能当作真实员工数据。

## 开通员工

1. 管理员进入「账号管理」→「开通账号」，填写姓名、独立账号、初始密码、账号权限及职位。
2. 在项目内点击「添加成员」选择该员工；也可从项目内直接「开通新成员」，自动加入当前项目。
3. 将正式平台网址、账号与临时密码通过公司可信渠道交给员工；平台不会自动发送邮件或短信。
4. 员工登录后先修改临时密码，再进入自己的工作台。

账号可以使用用户名、手机号或邮箱形式（3–64 位英文字母、数字、点、横线、下划线或 @，以字母或数字开头）。手机号只是账号名称，目前没有短信验证码登录。

职位提供工程师、管理员、销售、采购、人力，也可自行填写；职位与账号权限独立，选择“管理员”职位不会获得管理权限。职位、部门可在「管理」中修改。账号表单只设置身份资料与账号权限，不再提供成员关联或项目勾选；现有项目关系保持不变。

账号分为总管理员、管理员、员工。总管理员可开通、调整、停用、重置及删除管理员和员工账号；普通管理员只能管理员工，不能修改自己、其他管理员或总管理员的账号资料与权限。本人密码在「我的账号」修改。总管理员不能停用、降级或删除自身账号，平台只设一名总管理员；忘记密码时由服务器操作员线下恢复，普通管理员密码由总管理员重置。

删除账号会移除登录凭据、注销已有会话，保留业务成员、项目、任务及审批历史；原负责人不会自动改派。可重新开通同一登录名，但新账号不继承原账号的项目关系。

重置密码、停用、角色或员工项目权限变动会使原有登录失效；仅修改职位、部门不会退出登录。移出项目不会自动更换已有任务的负责人；项目负责人不能直接从自己负责的项目中移除。

| 角色 | 可见与可操作范围 |
| --- | --- |
| 总管理员 | 全部项目、全部账号管理、团队效能、平台备份与升级 |
| 管理员 | 全部项目、团队效能统计、员工账号管理与项目分配 |
| 员工 | 参与项目、代建任务、提交自己的成果和变更申请，可验收指定给自己的任务 |

项目负责人管理本项目计划、审批申请、验收大节点。总管理员可处理所有项目的变更与验收，也可处理自己的任务或申请。

权限由服务端逐次校验；员工无法通过更改网址或请求参数读取其他项目。临时密码登录不返回项目、任务或员工目录，只有改密和退出可用。账号停用不能撤回用户此前已看到或复制的内容。

## 手机桌面版

登录页和「我的账号」提供安装说明。iPhone/iPad 使用 Safari 的「分享」→「添加到主屏幕」；支持的安卓浏览器可使用「安装应用」或「添加到主屏幕」。网页版和桌面版连接同一服务器与数据库，无需上架应用商店。

这是 PWA，不是 APK/IPA 安装包。正式手机安装需要 HTTPS，具体入口因浏览器而异。使用时须联网；离线只显示连接提示，不缓存项目、账号数据，也不排队提交任务。手机键盘、安全区、实际安装及国内网络访问需在正式域名上实机验收。

## 项目与审批

- 新建项目可一次编排多组大节点和小任务，向审批中心提交一份计划。由拟任项目负责人或管理员批准后，项目上线并分配全部任务；驳回后提交人可修改重提。建项时无需先选择项目成员，节点分配生效时所选人员自动获得该项目的访问权。
- 项目中心默认流程图；顶部切换项目、查看全部项目和新建项目。旧管理后台链接自动返回项目中心。
- 大节点代表阶段或周目标，小节点代表任务。流程支持缩放、平移及全部/本周/我的任务筛选。
- 管理员和总管理员可直接创建大节点，无需申请或审批；员工新增大节点仍先申请。节点计划调整仍需审批，管理员可自批。新项目整份计划仍需提交审批。项目延期由项目负责人或总管理员审批，仅总管理员可以自批延期。
- 在大节点详情可以设置多位执行成员和多位其他验收人。由项目负责人主验，选中的其他验收人都需要分别签字。项目负责人必须本人签字，总管理员可代签一个加验席位。阶段和子任务分开验收，项目负责人参与过的子任务通过验收后，他仍能验收整个阶段。
- 项目负责人或管理员可以直接修改本项目的大小节点内容、改派未完成任务的验收人。待验收或已完成任务的验收标准保留。
- 所有项目成员均可创建任务，包括文职人员；另外指定实际负责人和任务验收人。系统记录真实创建人及创建时间，创建任务不会增加执行、验收或项目审批权限。
- 管理员和总管理员可删除小节点或大节点；删除大节点会同时删除其下属任务与附件。只有总管理员可删除整个项目及其节点、任务、附件与申请。删除前显示影响并要求确认，保留删除操作记录；员工及员工身份的项目负责人不能删除节点或项目。
- 小任务的「负责人」和「验收人」分别用复选框选择，每组至少一人。所有负责人同级，每位负责人分别提交个人成果，全部交齐后进入验收。所有验收席位都签字后才完成，任一人退回则重提重签。负责人和验收人均从全公司已开通登录的成员中多选，可勾选同一人。每个账号每轮限签一个席位。大节点须有至少一个小任务，且所有小任务均已验收。
- 大节点和小节点详情的截止时间旁可直接申请延期，自动绑定当前节点；项目延期入口直接显示在项目工具栏。节点延期仅调整该节点，若超过上级截止时间，则一并申请顺延所属大节点和项目，表单会列出具体日期变化。其他小节点保持原日期。延期由项目负责人或总管理员审批，仅总管理员可自批；批准前原计划继续生效，保留原始截止日期及申请记录。
- 本周必达包含此前遗留未完成的大节点；进度条上的圆圈标出正式大节点，可查看详情。未批准的节点不纳入正式进度。
- 项目中心展示项目进度与大节点；周计划提供节点与任务汇总。团队与效能保留个人完成率、按时交付率、汇总图和成员条形指标。

项目任务完成率按已验收任务占全部任务的比例计算。绿色表示实际完成率，右侧红色虚影表示与计划的差距。大节点圆圈显示阶段状态，双签阶段收到最后一份签字才标记完成。原签字之后若验收内容、相关任务或附件发生变化，未完成阶段需重新签字。

计划输入精确到小时，提交、审批和每次签字使用服务器时间，界面统一按北京时间显示到分钟。旧纯日期保留全天含义。获批的延期或节点调整才改变当前计划基准。

## 成员与工作通知

- 管理员可在已有项目的成员摘要或成员页点击“添加成员”，选择已启用的账号，或点击“开通新成员”创建账号并加入当前项目。保留员工其他项目关系，加入后按新的权限范围访问。
- 大节点和延期的申请原因、批准或驳回意见均为选填；审批动作、权限和日期校验保持不变。任务验收退回仍需填写修改意见。
- 任务、项目和审批变化会通知相关账号，并在对应记录、项目导航及顶部通知铃铛显示红色未读数字。自己的操作不会重复提醒自己；查看对应详情或选择“全部已读”后清除，已读状态保存在服务器。
- 未完成任务另有持续红点，项目显示未完成任务数。「我的任务」导航数字包含自己尚未验收完成的任务及待自己验收的任务，去重计数。只有验收通过（`done`）才消除；提交待验收仍算未完成。
- 「审批中心」持续统计当前可见项目中所有待审批申请，包括自己提交、等待他人审批的申请；批准或驳回后消除。「我的任务」与「审批中心」的待办提醒不受查看详情、全部已读、刷新或重新登录影响。
- 页面在空闲且可见时每 15 秒检查更新，切回窗口时刷新；编辑表单期间暂缓刷新。此功能为站内通知，不是短信或手机系统推送。

## 导出周汇总

在「周计划与汇总」选择一周，点击「导出 Excel」或「导出 Word」，下载 `.xlsx` 或 `.docx`。两种格式均含本周概况、项目进度、本周任务、本周大节点、下周计划五张表；任务表带负责人、截止/提交/验收时间和交付成果。

本周任务与大节点按所选周内的截止时间归属，下周计划按下一周截止时间归属，北京时间显示。项目进度是全部可见项目的当前进度；过去周报也采用导出时的当前状态，不回溯还原历史状态。管理员可导出全部项目，员工和项目负责人仅导出其有权查看的项目。

## 项目文件与备份升级

项目流程中，“我的任务”后为“文件管理中心”，按大节点分组显示当前项目文件，每组包含大节点直属文件和下属任务附件。可按文件名、上传人搜索；文件行标明所属大节点/任务、上传人、时间和大小。拖到流程图中的大节点或小任务卡片即可上传，节点详情也直接上传到当前节点。卡片的回形针数字显示附件数量，大节点含下属小任务。文件管理中心上传时再选择所属大节点。单文件上限 20 MB，多选依次上传，同名文件分别保存。上传本身不代表提交或验收完成。

员工只能查看、上传和下载参与项目的文件；上传人、项目负责人及管理员可删除文件。文件内容与账号、项目一起保存在 SQLite 中，完整备份会一并包含。业务 JSON 导出不包含附件。

总管理员在“平台设置 → 备份与升级”管理每日自动备份，默认北京时间 02:00、保留最近 14 份自动备份；也可立即完整备份及下载。备份需要服务器运行，停机后会补做当天已到时间但尚未完成的备份。手动和升级前备份不受自动保留份数清理。完整备份含登录凭据，普通管理员不能访问备份和升级功能。

使用新版启动入口运行后，可选择本平台发布的独立 ZIP 更新包，检查完成再点击“备份并升级”。平台会暂停写入、完整备份、替换程序并自动重启；保留账号、密码、项目、任务、附件和运行配置。新版启动失败时恢复升级前程序和数据库；只有启动验证及成功记录完成后才恢复业务写入。详细步骤见 [部署说明](DEPLOYMENT.md)。

## 数据与验证

独立版使用服务器 SQLite，数据文件默认 `data/dinfon.sqlite`；运行配置为 `config/runtime.json`，均不随发布包或源码提交。业务写入采用版本条件更新，冲突返回 409 而不覆盖他人修改。账号密码使用加盐 scrypt 哈希，会话使用 HttpOnly Cookie，服务器只存会话令牌摘要；登录失败有持续化限流，正式网址要求 HTTPS。

总管理员可在平台设置导出业务 JSON，周报按当前账号权限导出。业务导出不含密码、会话、账号绑定，不能替代完整数据库备份。部署包不含真实数据库、运行配置或测试账号凭据。暂未实现手机系统推送、短信验证码、自动邀请、离线编辑、自动生成周期任务或复杂任务依赖。

```sh
npm test
npm run check
npm run backup
```

`npm test` 包括业务规则、角色和项目范围、账号会话、首次改密、重置/停用、项目分配、HTTP 服务与 PWA 缓存边界测试。通过测试不代表国内网络、真实员工多人使用或手机安装已完成验收。

## 源码结构

```text
public/client/          界面、流程图、可视化与业务领域模块
public/sw.js            仅缓存通用离线提示的 Service Worker
public/manifest.webmanifest  手机桌面版配置
server/service.mjs      账号、业务权限、审批、版本条件写入
server/auth.mjs         密码哈希、会话、限流
server/standalone.mjs   独立 HTTP 服务与静态资源入口
server/sqlite.mjs       SQLite 数据库与原子事务适配
scripts/setup-local.mjs 首次配置（密码只在终端输入）
scripts/manage-admin.mjs 服务器管理员恢复/迁移
scripts/backup.mjs      完整数据库快照
Dockerfile / deploy/    容器与 HTTPS 反向代理配置
tests/                  自动化测试
```

原 Sites/Vinext 适配代码保留在完整工作区，独立部署包不依赖它。旧版 `handleApi` 只作内部业务适配及回归测试入口；对外服务必须使用 `handleHttpApi`，不能从客户端传入模拟身份。
